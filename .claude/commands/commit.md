# commit

변경 사항을 논리 단위로 묶어 커밋.

$ARGUMENTS:
- 없음 → **세션 모드**: 이 세션에서 건드린 파일만
- `all` → **전체 모드**: 모든 미커밋 변경 파일

---

## 공통 1단계 — 현황 파악

`git status`와 `git diff HEAD` 실행 → 전체 미커밋 변경 파일 목록 확인.

---

## 세션 모드

### 2. 세션 구분

- **이 세션에서 변경한 파일** — 현재 대화에서 직접 읽거나 수정한 파일
- **이 세션에서 건드리지 않은 파일** — 미커밋이지만 이 대화와 무관

후자는 커밋 대상 **자동 제외**. 목록만 간략히 표시.

### 3. 제외 파일

- `*.log` 커밋 안 함.
- `static/` 또는 `image/` 하위 untracked 파일은 포함 여부 먼저 묻는다.

### 5. 그룹핑 및 메시지 초안

논리적 단위로 묶어 메시지 초안과 함께 유저에게 제안. 승인 없이 커밋 금지.

### 6. 커밋 실행

승인된 그룹 순서대로 커밋.

---

## 전체 모드 (all)

### 2. 전체 변경 조사

미커밋 파일 전체 대상. 세션 구분 없음. 각 파일 `git diff HEAD -- <file>`로 변경 의도 파악.

### 3. 제외 파일

- `*.log` 커밋 안 함.
- `static/` 또는 `image/` 하위 untracked 파일은 포함 여부 먼저 묻는다.

### 5. 그룹핑 및 메시지 초안

모든 변경 파일을 논리적 단위로 묶어 커밋 플랜 전체 표시:

```
[커밋 1] feat: ...
  - ui/foo.py
  - calculator/bar.py

[커밋 2] fix: ...
  - data/baz.json
```

승인 없이 커밋 금지.

### 6. 커밋 실행

승인된 그룹 순서대로 커밋.

---

## 메시지 형식

```
[캐릭터명] 추가
[stat명] 구현
feat: 기능 추가 내용
fix: 버그 내용
perf: 성능 개선 내용
refactor: 리팩터링 내용
docs: 문서 업데이트 내용
chore: 설정·도구 변경
```
